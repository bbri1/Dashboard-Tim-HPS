    Panduan cepat Dashboard HPS

    Angka-angka di atas

    • Total HPS — HPS aktif = Done + On Progress (Cancel dan HPS tanpa status tidak dihitung), sama seperti sheet Rekap All Team di Excel.
    • Nilai HPS Selesai — total nilai HPS untuk status Done.
    • Selesai (Done) — Done ÷ Total HPS aktif.
    • Sedang Diproses — On Progress = Putusan + Draft Putusan + Proses Analisa + RFI + Pre-Screening.
    • Rata-rata SLA — rata-rata SLA per estimator (pembulatan ke atas, seperti rumus ROUNDUP di rekap), untuk estimator dengan ≥5 data.
    • Perlu Perhatian — HPS On Progress yang sudah lebih dari 30 hari.
    • Tabel SLA per Estimator memakai kolom Terukur (= jumlah HPS Done), Rata² (ROUNDUP), Median, dan sebaran kategori 1–10 / 11–15 / >15 hari — identik dengan rekap.

    Cara cepat checking data

    • Klik baris tabel → panel detail: identitas, nilai anggaran vs nilai HPS, selisih, SLA, dan alur tahapan lengkap dengan tanggalnya.
    • Filter cepat (kiri atas): Perlu perhatian, SLA > 15 hari, Belum ada nilai — langsung melompat ke data bermasalah.
    • Simpan tampilan — simpan filter yang sering dipakai; tersimpan di server sehingga bisa dipakai rekan lain juga.
    • Salin tautan (di panel detail) — alamat browser menyimpan filter; tinggal kirim ke rekan.
    • Tombol kolom (kanan atas) — nyalakan kolom tambahan: Tgl Pre-Screening, Tgl Dok. Lengkap, Tgl Putusan, Tgl Rilis, Nilai Anggaran, SLA, Kategori SLA.
    • Status per Tim — klik angka untuk langsung memfilter tim + status tersebut.
    • Bandingkan periode lalu — menampilkan perubahan tiap angka KPI dibanding bulan sebelumnya.

    Shortcut

    • / fokus ke kolom pencarian · Esc keluar pencarian / tutup panel
    • Klik judul kolom untuk mengurutkan (klik lagi untuk membalik)
    • Ctrl+P cetak — header laporan berisi filter & waktu cetak

    Data & pembaruan

    • Data dibaca dari file Excel oleh server, lalu ditampilkan di semua layar. Layar otomatis ter-update paling lama 60 detik setelah ada file baru.
    • Angka "umur HPS" dihitung dari Tgl Permintaan sampai hari ini, jadi bertambah setiap hari.
    • Status kosong ditampilkan sebagai Tanpa Status supaya tidak ada HPS yang luput dari hitungan.
