DASHBOARD PROGRES HPS - PANDUAN SINGKAT (JARINGAN KANTOR)
=========================================================
Berjalan di jaringan lokal kantor. Tidak perlu internet.
Situs publik di internet sudah DIMATIKAN.

A. SETUP PC SERVER (sekali saja, di PC yang nyala jam kerja)
  1. Salin folder ini ke PC server, contoh: C:\HPS-Dashboard
  2. Pasang Python 3 di PC itu, lalu jalankan di CMD:
         pip install openpyxl
  3. Klik 2x install_service.bat  (akan minta hak admin)
     -> service auto-start + auto-restart, port 8080 dibuka di firewall
  4. Cek IP PC server:  ipconfig   (misal 192.168.1.20)
  5. Sampaikan ke rekan:
         DASHBOARD  : http://<IP-PC-SERVER>:8080/
         UNGGAH     : http://<IP-PC-SERVER>:8080/upload.html
  Detail lengkap: LAN_SETUP.md

B. UPDATE DATA (laptop boleh mati)
  CARA A - dari browser mana pun di kantor:
     buka http://<IP-PC-SERVER>:8080/upload.html
     drag file Excel (.xlsx) ke kotak -> "Berhasil! 1459 baris"
     semua layar ter-update otomatis dalam maks 60 detik (tidak perlu F5)
  CARA B - salin file .xlsx ke folder server (C:\HPS-Dashboard)
     server rebuild otomatis dalam 20 detik
  CARA C - di PC server: klik 2x update_data.bat

C. JIKA INGIN JALAN 24 JAM (PC kantor sering dimatikan)
  Pakai Raspberry Pi / mini PC (~Rp500-800rb) + Docker:
     docker compose up -d
  (file: Dockerfile, docker-compose.yml, hps-dashboard.service)

D. ISI FOLDER
  index.html            tampilan dashboard
  upload.html           halaman unggah Excel
  data.js               data hasil baca Excel (otomatis dibuat)
  data.meta.json        timestamp + jumlah baris (dipakai cek perubahan)
  server.py             server lokal (API + watcher)
  update_data.py        Excel -> data.js
  update_data.bat       build data.js di PC server
  install_service.bat   pasang service Windows (auto-start + firewall)
  uninstall_service.bat copot service
  start_server.bat      jalanin server manual (testing)
  publish_data.bat      opsional: salin data ke repo cadangan GitHub
  Progress_Report_HPS.xlsx  sumber data (benar)
  Dockerfile / docker-compose.yml / hps-dashboard.service  untuk Pi/NAS/Linux

E. CATATAN
  - PC server harus menyala; kalau dimatikan malam, dashboard ikut mati.
  - Jangan ubah nama sheet / urutan header di Excel.
  - Umur HPS On Progress dihitung dari Tgl Permintaan sampai hari ini.
  - Repo GitHub hanya cadangan (situs publik sudah dimatikan).
  - Troubleshooting: LAN_SETUP.md
